What should a chatbot do when the handbook is silent?

In the fictional handbook example, there is no bicycle repair policy. A referral to HR is only part of a good answer. If the same response invents a reimbursement amount, the evidence check fails. The workbook flags the row for review.

How to evaluate your own assistant

  1. Pick questions that employees actually ask. Include an ambiguous question, an outdated document and a question from someone without access.
  2. Before running a test, write the expected response and the source, follow-up question or referral that would justify it.
  3. Record what the chatbot did and mark whether its evidence met the rule. Rerun the same cases after changing a policy, permissions or the model.

Each download includes 30 rows with formulas. Replace the fictional entries or start in a blank row. You can use the workbook offline.
