Accessibility statement

We want everyone to be able to use mvtech.solutions, including people who rely on a keyboard, a screen reader, magnification or other assistive technology.

Last reviewed:

Our standard

We aim for this website to conform to the Web Content Accessibility Guidelines (WCAG) 2.1 at Level AA, the standard most often used to judge website accessibility in the United States.

How we build for access

  • Pages use semantic HTML with landmarks, one main heading and a logical heading order.
  • A “Skip to content” link is the first item on every page, and every control works with a keyboard and shows a visible focus outline.
  • Images that carry meaning have text alternatives; decorative images are hidden from screen readers.
  • Text and controls use a color palette chosen for readable contrast.
  • Animation is reduced when your device asks for reduced motion.
  • All page content is in the HTML, so it can be read without JavaScript.
  • Automated checks run on every release and fail the build if a page is missing its language, has more than one main heading, has an image without a text alternative, repeats an element ID or opens a new window unsafely.

Known limitations

  • The booking calendar is provided by Calendly, a third party. If it is hard to use, email us and we will arrange a time directly.
  • Some PDF files in the downloadable brand kit may not be fully tagged for screen readers. We can send the same information in another format.

Report a barrier

If something on this website is hard to use, tell us. Email contact@mvtech.solutions with “Accessibility” in the subject line, the page address and what happened. We will reply, provide the information you need in another way and work on a fix.
