How to compare a real report

  1. Pick one measure and align the dates, filters, currency and reporting cutoff in both systems.
  2. Enter the two totals and the largest absolute difference the report owner accepts. Use zero for an exact match.
  3. Assign each exception to an owner. Trace the differing records, correct the cause and run the comparison again before retiring the old report.

Each download includes 30 rows with formulas. Replace the fictional entries or start in a blank row. You can use the workbook offline.
