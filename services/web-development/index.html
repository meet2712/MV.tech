Before we begin

Questions about web development

Not answered here? Ask us directly or read the full FAQ.

Which web technologies do you use?

React and Next.js for front ends; Node.js and TypeScript (Express or NestJS) or Python (Django, Flask or FastAPI) for backends; PostgreSQL for data. We can also work in your existing stack after reviewing it.

Can you rebuild our website without losing search rankings?

Yes. We map the existing URLs, carry over titles, metadata and structured data, and redirect anything that moves, so search engines can follow the change.

Will the new site be fast and accessible?

We work to WCAG 2.1 AA, measure Core Web Vitals before release and fix the issues that matter most to your users first.

Can your developers work in US business hours?

Yes. With staff in New York and Ahmedabad, we agree a recurring collaboration window in US Eastern or Pacific time, with written updates between meetings.

How do you price web development?

We quote after a scoping call, based on the pages, user journeys, integrations and release plan. A first milestone is agreed in writing before work starts.
